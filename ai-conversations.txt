part = state.parts[part_index]
This gets the selected part. The route then calls the existing part_form with all its current values. Quantity becomes str(part.quantity) because it goes into a text box.

The form’s Save Changes button carries that same index:
Button("Save Changes", update_part, {"part_index": part_index})
update_part receives the index along with the values you entered. It passes them to the existing store_part function, which:
- Checks required fields, positive quantity, and duplicate part numbers.
- Shows the form with your entries and an error message if validation fails.
- Replaces the selected entry if validation succeeds:
state.parts[part_index] = part
Then it returns to the BOM. Because the index stays the same throughout, changing the part number still updates the original row.

Both new routes also check that the index is valid. If it isn’t, they return to the BOM without changing anything.
